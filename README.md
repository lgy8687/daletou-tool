# 大乐透选号与历史数据

这是一个浏览器端选号和历史数据查看工具。打开 `index.html` 即可使用；网页依赖 Tailwind CDN 加载样式，需要网络。生成号码只是随机与规则筛选，并不能证明提高中奖概率。开奖与投注请以中国体育彩票官方渠道的信息与规则为准。

## 文件

- `index.html`：网页入口。
- `函数代码.js`：选号、数据管理、界面与回测函数。
- `历史期数.js`：网页初始使用的最近100期数据。
- `历史回测200期.json`：供独立回测使用的200期数据。
- `官方历史回测600期.json`：供独立回测使用的600期数据。
- `函数想法说明.md`、`回测结果说明.md`、`中奖概率专项验证.md`：算法与验证说明。

## 重要说明

网页默认的最近100期截至第26122期，不会自动联网更新。用户可以在页面录入新开奖数据，但结果仅保存在当前设备的当前浏览器中；不同浏览器或设备之间不会自动同步，清理浏览器数据可能导致已录入信息丢失。网页界面只保留最近100期；200期和600期文件作为独立数据保存在仓库，不要直接粘贴到网页的保存框。

这是个人工具，与中国体育彩票官方没有关联；如果用于销售网点展示，请先与当地体彩管理部门核实相关要求。历史数据和规则可能变化，须使用官方公告核对。
